# トークンリフレッシュ

## 基本情報

| 項目 | 内容 |
|------|------|
| エンドポイント | `POST /api/v1/auth/refresh` |
| 概要 | リフレッシュトークンを使用して新しいアクセストークンを発行する |
| 認証 | 不要（リフレッシュトークンcookieが必要） |

## リクエスト

リクエストボディは不要です。`refreshToken` cookieが自動送信されます。

### Cookie

| 名前 | 必須 | 説明 |
|------|------|------|
| refreshToken | Yes | ログイン時に発行されたリフレッシュトークン |

## 成功レスポンス

**ステータスコード: 200 OK**

| フィールド | 型 | 説明 |
|-----------|-----|------|
| accessToken | String | 新しいアクセストークン（JWT） |
| expiresIn | Long | アクセストークン有効期限（秒） |

```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiIs...",
  "expiresIn": 3600
}
```

## エラーレスポンス

| ステータスコード | 説明 |
|-----------------|------|
| 401 Unauthorized | リフレッシュトークンが未送信または無効 |
