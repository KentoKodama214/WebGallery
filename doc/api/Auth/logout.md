# ログアウト

## 基本情報

| 項目 | 内容 |
|------|------|
| エンドポイント | `POST /api/v1/auth/logout` |
| 概要 | リフレッシュトークンを無効化し、cookieを削除する |
| 認証 | 不要 |

## リクエスト

リクエストボディは不要です。`refreshToken` cookieが自動送信されます。

### Cookie

| 名前 | 必須 | 説明 |
|------|------|------|
| refreshToken | No | ログイン時に発行されたリフレッシュトークン |

## 成功レスポンス

**ステータスコード: 204 No Content**

レスポンスボディはありません。レスポンスヘッダーの `Set-Cookie` でリフレッシュトークンcookieが削除（`maxAge=0`）されます。
