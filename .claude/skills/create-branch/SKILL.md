# Create Branch

## 1. 入力の取得と解析
   - ユーザーから作業内容（例: ログイン機能の実装）を受け取る。
   - 入力が曖昧な場合は、どのような作業を行うか簡潔に質問する。

## 2. 事前チェック
   - `git status --porcelain` で作業ツリーの変更を確認する。
   - 変更がある場合はユーザーに通知し、「スタッシュして実行」「そのまま新しいブランチに引き継ぐ」「中止」を選択させる。

## 3. ブランチ名の生成と確認
   - 命名規則: `<type>/<short-description-in-kebab-case>`
   - 例: `feature/add-fastapi-endpoint`
   - 生成したブランチ名をユーザーに提示し、即時実行する。

## 4. 実行手順
   - `git checkout main` （または設定されたデフォルトブランチ）
   - `git pull origin main` で最新化
   - `git checkout -b <生成されたブランチ名>` を実行
   - 正常に切り替わったことを `git branch --show-current` で提示する。
