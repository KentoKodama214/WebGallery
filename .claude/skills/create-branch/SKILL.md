# Create Branch

## 1. 入力の取得と解析
   - ユーザーから作業内容（例: ログイン機能の実装）を受け取る。
   - 入力が曖昧な場合は、どのような作業を行うか簡潔に質問する。

## 2. 事前チェック
   - `git status --porcelain` で作業ツリーの変更を確認する。
   - 変更がある場合は確認せず、そのまま新しいブランチに引き継ぐ（スタッシュ・破棄は行わない）。

## 3. ブランチ名の生成と確認
   - 命名規則: `<type>/<short-description-in-kebab-case>`
   - 例: `feature/add-fastapi-endpoint`
   - 生成したブランチ名をユーザーに提示し、即時実行する。

## 4. 実行手順
   - 作業ツリーに変更がない場合: `git checkout development` （または設定されたデフォルトブランチ）→ `git pull origin development` で最新化 → `git checkout -b <生成されたブランチ名>` を実行
   - 作業ツリーに変更がある場合: デフォルトブランチへの切り替え・最新化は行わず、現在のブランチから直接 `git checkout -b <生成されたブランチ名>` を実行（変更を引き継ぐ）
   - 正常に切り替わったことを `git branch --show-current` で提示する。
