# データベースの設計ルール

## スキーマ
- スキーマの一覧と責務は以下の通り
  - common: すべてのドメイン領域、アプリケーションに共通するデータを管理するスキーマ
  - photo: 写真関連のドメイン領域に関するデータを管理するスキーマ
- 新しいスキーマの定義はユーザーが行うため、Claude は新しいスキーマは作らない

## テーブル
- テーブル名は、ローワースネークケース（lower_snake_case）で命名する
- 主キーは、外部キー（Surrogate Key）で定義する

## カラム
- カラム名は、ローワースネークケース（lower_snake_case）で命名する
- すべてのカラムに、Not Null制約をつける
- 外部キー制約は必ず設定する
- 区分値の型は、CREATE TYPEで定義した型を使用する
- 作成者（created_by）、作成日時（created_at）のカラムは必ず付ける
- レコードの更新が発生するテーブルには、必ず更新者（updated_by）、更新日時（updated_at）を付ける
- 論理削除が発生するテーブルには、必ず削除フラグ（is_deleted）を付ける
- すべてのカラムにコメントを付ける
