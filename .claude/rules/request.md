# Requestクラスのアーキテクチャルール

## 命名規則

- クラス名サフィックス: `Request`

## プロパティ
- ドメインクラス（値オブジェクト）、Modelクラス、Dtoクラス、Entityクラスは使用しない（依存性・責務の分離のため）

## バリデーションアノテーション

- リクエストクラスのプロパティにはバリデーションアノテーション（`@NotNull`、`@NotBlank`、`@Size`等）を付与すること
- バリデーションアノテーションが一つも存在しないRequestクラスは違反
